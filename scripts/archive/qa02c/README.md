Its companion runtime/browser scripts and historical inputs remain in the private
source preservation snapshot; they are deliberately not another application source tree.

The active published Docker helper remains ../../demo/demo.ps1. Do not rename this
archive to Demo.ps1 or copy it over that file on Windows. Legacy integration uses
the separate legacy configuration and never this QA wrapper.
